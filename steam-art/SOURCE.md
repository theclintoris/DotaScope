# Steam artwork sources

The custom Steam library art in this folder uses the **Shattered Sanity** Immortal set for **Ancient Apparition** from Dota 2's **Trove of Terror**.

- Set reference and article: [Cyber.Sports.ru — Trove of Terror set overview](https://cyber.sports.ru/dota2/blogs/3548089.html)
- Source render: [Cyber.Sports.ru image CDN](https://photobooth.cdn.sports.ru/preset/message/8/2f/be63b41b84b89874e8d66b29cf9e8.jpeg?f=webp&q=90&s=2x&w=730)
- Saved source: `source-shattered-sanity.webp`

Dota 2, Ancient Apparition, Shattered Sanity, and related art are trademarks and copyrights of Valve Corporation. This artwork is included for a personal, non-commercial Steam library customization and is not affiliated with or endorsed by Valve.

The composite art (wordmark, layout, gradients, icon crop) was generated locally by `scripts/make-steam-art.py`. Steam's `_hero` image is intentionally clean because Steam overlays the transparent `_logo` image at runtime.
